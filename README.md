# 超星学习通 · 未完成作业查询脚本

登录后遍历账号下所有课程，筛选出未完成的作业，并且按剩余时间由近到远排序，
结果写入桌面的 `unfinished_homework.txt` 并自动打开。

## 使用

需要 Windows + Python 3.10+。

```bash
pip install requests pycryptodome
python main.py
```

或直接双击脚本运行。

首次运行按提示输入手机号和密码，之后自动登录；启动后 3 秒内按任意键可输入新账号进行查询。

账号密码以AES密文保存在 `~/.xuexitong_homeworkcheck/config.json`，
旧版本留下的明文配置会在首次运行时自动迁移成密文。

结果示例：

```
未完成作业（共 2 条）

最临近提交：【计算机网络】第3章作业
           剩余：剩余2小时15分钟（2小时15分钟后）

【课程】计算机网络（1 项作业）
  作业：第3章作业
  剩余：剩余2小时15分钟（2小时15分钟后）

【课程】人工智能导论（1 项作业）
  作业：神经网络基础
  剩余：剩余27小时0分钟（1天3小时后）
```
