# 超星学习通 · 未完成作业查询脚本

登录学习通后，遍历当前账号下所有课程，抓取作业列表并筛选出未完成的作业，
按剩余时间由近到远排序输出，便于优先处理临近截止的任务。

## 功能特性

- 自动登录学习通（手机号 + 密码，AES 加密表单）
- 遍历账号下所有课程，抓取每个课程的作业列表
- 过滤掉已完成状态（已完成 / 已提交 / 待批阅 / 已批阅 / 已批改 / 已互评）
- 输出未完成作业，按截止时间由近到远排序
- 标识最临近提交的一条作业，并换算为「X天X小时X分钟后」的直观描述
- 登录态失效时自动重新登录并重放请求，网络异常带退避重试

## 运行环境与依赖

- Python 3.8+
- `pip install requests pycryptodome`

## 使用方法

1. 修改脚本开头「配置区」中的 `PHONE` 和 `PASSWORD` 为你的学习通账号与密码。
2. 直接运行脚本：

```bash
python main.py
```

3. 脚本会打印未完成作业清单，形如：

```
==============================
未完成作业（共 2 条）
==============================

最临近提交：【计算机网络】第3章作业
           剩余：剩余2小时15分钟（2小时15分钟后）

【课程】计算机网络（1 项作业）
  作业：第3章作业
  剩余：剩余2小时15分钟（2小时15分钟后）

【课程】人工智能导论（1 项作业）
  作业：神经网络基础
  剩余：剩余27小时0分钟（1天3小时后）
```

## 输出格式说明

- 每门课程会单独分组展示，顺序按该课程最早截止时间排列。
- 无截止时间的作业排在最后，标注为「无截止时间」。
- 已完成状态的作业不会出现在结果中。

## 注意事项

- 若账号名下课程较多，脚本抓取可能较慢，请耐心等待。
- 脚本中的 AES 密钥为学习通登录表单使用的固定密钥，无需改动。
