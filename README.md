# 超星学习通 · 未完成作业查询脚本

双击运行，自动登录学习通，遍历账号下所有课程，抓取作业列表并筛选出**未完成**的作业，
按剩余时间由近到远排序，写入桌面的 `unfinished_homework.txt` 并自动打开。

不用再翻课程列表、不用再逐门点开作业页，临近截止的任务一眼可见。

## 功能特性

- **首次运行引导登录**：手机号 + 密码（AES 加密表单），自动保存到本地配置文件，之后免输入
- **一键换号**：启动后 3 秒内按任意键即可修改账号，否则直接沿用已保存账号
- **自动遍历全部课程**：从课程列表提取隐藏参数，逐门进入作业模块抓取
- **精确的状态判定**：只收录「未交」与「待互评」，已完成 / 已提交 / 待批阅 / 已批阅 / 已互评 / 已批改一律不计
- **待互评单独提示**：标题后追加「（待互评）」，避免漏掉需要给同学打分的作业
- **按截止时间排序**：最临近提交的一条置顶，并换算成「X天X小时X分钟后」的直观描述
- **按课程分组输出**：分组顺序 = 各课程最早截止时间的顺序；无截止时间的排最后
- **结果落到桌面文件**：通过注册表读取真实桌面路径，兼容 OneDrive 重定向与中文系统，写完自动打开
- **登录态自愈**：被踢回登录页时自动重新登录并重放请求；网络抖动带退避重试

## 运行环境与依赖

- **Windows**（脚本用到 `winreg`、`msvcrt`、`os.startfile`，其他系统不支持）
- Python 3.10+（类型标注使用了 `str | None` 写法）
- 依赖安装：

```bash
pip install requests pycryptodome
```

或直接：

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 运行脚本

```bash
python main.py
```

### 2. 首次运行：按提示输入账号

```
==============================================
 超星学习通 · 未完成作业查询
==============================================
首次运行，需要先登录学习通账号。
登录后脚本会查询账号下的未完成作业。

手机号: 13800000000
密码:   ******
```

账号密码会保存到 `%USERPROFILE%\.xuexitong_homeworkcheck\config.json`，下次运行自动读取。

### 3. 再次运行：自动登录

```
检测到已保存的学习通账号：13800000000
接下来将登录该账号，抓取各课程中未完成的作业，
**如需更换账号，请在 3 秒内按任意键**；否则自动继续……
  倒计时 3 秒，按任意键修改账号…
```

- 什么都不按 → 直接查询已保存账号
- 3 秒内按任意键 → 重新输入手机号与密码，并覆盖保存

也可以直接删除 `%USERPROFILE%\.xuexitong_homeworkcheck\config.json`，效果等同换号。

### 4. 查看结果

查询结束后会打印 `查询完成`，并自动用记事本打开桌面上的 `unfinished_homework.txt`，内容形如：

```
==============================
未完成作业（共 3 条）
==============================

最临近提交：【计算机网络】第3章作业
           剩余：剩余2小时15分钟（2小时15分钟后）

【课程】计算机网络（2 项作业）
  作业：第3章作业
  剩余：剩余2小时15分钟（2小时15分钟后）
  作业：小组讨论（待互评）
  剩余：无截止时间

【课程】人工智能导论（1 项作业）
  作业：神经网络基础
  剩余：剩余27小时0分钟（1天3小时后）
```

## 输出格式说明

- **最临近提交**：全部结果中截止时间最近的一条，单列展示。
- **【课程】**：每门课程单独分组，组内按截止时间升序。
- **作业**：标题；若状态为「待互评」，标题后带「（待互评）」。
- **剩余**：原文「剩余X小时Y分钟」后附「（X天X小时Y分钟后）」换算；无截止时间显示「无截止时间」。
- 无任何未完成作业时，文件中只写一行「暂无未完成作业。」。

## 常见问题

**Q：提示「暂无未完成作业」，但我确实有作业？**
脚本只统计有作业模块的课程。若课程页取不到 `workEnc` 参数（该课程没开作业功能），会被跳过；
另外若作业状态是学习通新增的、脚本未识别的状态值，也会被忽略。可对照学习通网页端确认。

**Q：运行报 `ModuleNotFoundError: No module named 'Crypto'`？**
装依赖：`pip install pycryptodome`（注意不是 `pycrypto`）。

**Q：config.json 里密码是明文吗？**
是。它只用于登录前做 AES 加密，落盘时并未加密。请勿把该文件上传或分享给他人。

**Q：可以放到 Mac / Linux 上跑吗？**
不行，脚本依赖 Windows 专有的 `winreg`、`msvcrt`、`os.startfile`。

**Q：课程多的时候很慢？**
每门课程需要 2 次请求（课程主页 + 作业列表），课程越多耗时越长，属正常现象。
